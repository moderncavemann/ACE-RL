# Frozen Experiment Status

The controlled ABCE primary study and the exact risk-only official-learner
holdout are complete. No additional formal training is required for the
current narrow claim. No result-triggered parameter search, seed replacement,
episode extension, or selective learner reporting was used after the relevant
protocols were frozen.

## Decisions

| Experiment family | Frozen decision |
| --- | --- |
| ABCE A: state alignment | Exact random, circular shift, and periodic schedules are worse than aligned timing; every contrast is positive for 20/20 policy populations |
| ABCE B: timely pre-quote revelation | Current-contract revelation is better than one-step-lagged revelation, 20/20 positive; this is not a universal transparency claim |
| ABCE C1: quote-sensitive allocation | Quote-aligned soft-rank allocation is better than identity-permuted redistribution with the same allocation-weight multiset, 20/20 positive |
| ABCE C2: allocation-family transfer | The timing advantage also appears under the tested hard-best contract, 20/20 positive; only two allocation families were tested |
| Same-panel no-routing reference | Returns near untreated behavior and supports the routing channel; it is not a confirmatory no-intervention arm |
| Exact risk-only official MAPPO | Supported by the primary policy-seed t interval, exact sign test, and two-way bootstrap; 9/10 positive |
| Exact risk-only official IPPO | Positive point estimate but primary t interval crosses zero; inconclusive and no learner-independent claim |
| Earlier adaptive-v5 fresh panel | Retained as an independent replication, not the headline ABCE effect and not pooled |
| Dose curve | Mixed; matched random wins at dose 0.10 and the reversal is retained |
| Forced-undercut diagnostic | Supports high-spread coordination only; punishment/retaliation claim rejected |
| Brero/Banerjee ABIDES adaptations | Executable but descriptive because frozen convergence and/or matching gates failed |
| Frozen efficiency profile | Complete as a non-outcome control-path microbenchmark; no production-efficiency claim |

## Scope Boundary

The supported statement is restricted to controlled N=10 ABIDES dealer
markets. Aligned routing improves the preregistered low-risk execution endpoint
by reducing unnecessary high-risk contract exposure; it does not improve
execution in every state and is not a total-welfare result. Use
`high-spread coordination`, not punishment-supported or learned collusion.

Do not claim universal cross-learner performance, allocation-mechanism
independence, superiority over original external mechanisms, larger-N
robustness, cross-matching-engine validity, or real-market effectiveness.
The emulated-container mechanism profile also does not establish native
production latency, negligible overhead, or full exchange-step efficiency.

The optional same-panel frozen no-intervention descriptive evaluation was not
needed for A/B/C inference and was not added after seeing outcomes. No routing
is labeled explicitly as the same-panel mechanism reference.

Development archives, superseded summaries, engineering screens, local
workstation outputs, author metadata, and source-repository history are outside
this anonymous release. Negative evidence that changes the scientific
conclusion remains included.
